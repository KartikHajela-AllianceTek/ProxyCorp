# ProxyCorp: Enterprise Multi-Agent Architecture

This project is a **multi-agent AI system** designed to mimic a real-world corporate hierarchy. It operates as an autonomous orchestration engine that routes tasks, checks schedules, and executes communications seamlessly.

The goal of this project is to understand how **specialized AI agents can communicate with each other, coordinate project requirements, and make collaborative decisions** using a structured, state-aware architectural flow.

In this system, different agents work together to **process client requests, delegate technical tasks, and manage human-in-the-loop (HITL) communications** like emails and meeting invites.
